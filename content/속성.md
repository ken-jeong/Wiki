속성은 노트 맨 위의 `---` 사이에 기록하는 정보이다.
이 Vault에서 사용하는 속성을 기준으로 정리했다.

## 공통 속성
| 속성        | 설명                                             | 예시                    |
| --------- | ---------------------------------------------- | --------------------- |
| `aliases` | 노트를 찾거나 연결할 때 사용할 다른 이름.                       | `Process`, `프로세스`     |
| `type`    | 노트의 종류. 아래 다섯 가지 값을 사용한다.                      | `Lecture`             |
| `tags`    | 주제나 성격을 표시하는 분류 키워드.                           | `Networks`, `Seminar` |
| `draft`   | 초안·정리 중 여부. `true`는 정리 중, `false`는 정리 완료로 읽는다. | `true`                |
| `date`    | 노트의 기준 날짜. 강의·행사일 또는 작성일 등 문맥에 따라 해석한다.        | `2026-09-27`          |

### type 값
- `Lecture`: 강의와 학습 내용을 정리한 노트.
- `PARA`: 프로젝트·관리 영역·참고 자료·보관 자료에 해당하는 노트.
- `Ontology`: 개념을 설명하고 다른 개념과의 관계를 연결하는 노트.
- `Index`: 폴더나 주제의 노트 목록을 모은 목차.
- `Board`: 칸반 보드로 사용하는 노트.

## 개념 간 관계
현재 `Ontology` 노트에서 사용하는 속성이다.
기존 연결 사례를 기준으로 다음처럼 이해할 수 있다.

| 속성 | 설명 | 예시 |
| --- | --- | --- |
| `up` | 상위 개념이나 자신을 포함하는 개념. | HTTP → TCP-IP |
| `down` | 하위 개념이나 세부 주제. | 프로세스 → 스레드 |
| `same` | 같은 수준에서 함께 살펴볼 관련 개념. | HTTP 상태 코드 → HTTP 버전 |
| `prev` | 앞서 이해하거나 먼저 읽을 개념. | HTTP → TCP-IP |
| `next` | 이어서 살펴볼 개념. | HTTP → HTTP 상태 코드 |

`up`·`down`은 개념의 계층, `prev`·`next`는 읽거나 학습하는 흐름을 나타낸다.
같은 노트가 두 관계에 함께 들어갈 수도 있다.

## 기타 속성
- `kanban-plugin`: 칸반 플러그인용 속성. [[P1_Project/PROJECT|PROJECT]]에서 `board` 값을 사용한다.
- `cssclasses`: 노트에 적용할 CSS 클래스 목록. 속성 설정에는 등록되어 있지만, 현재 노트에서는 사용하지 않는다.

## 입력 예시
아래는 관계 속성의 입력 형식을 보여 주는 예시다.

```yaml
up:
  - "[[TCP-IP]]"
next:
  - "[[HTTP 상태 코드]]"
  - "[[HTTP 버전]]"
```

- 여러 값은 `-`로 나열하고, 노트 링크는 `"[[노트 이름]]"` 형식으로 적는다.
- `[]` 또는 값이 없는 속성은 아직 등록한 내용이 없다는 뜻이다.
- 날짜는 `YYYY-MM-DD`, 체크박스 값은 `true` 또는 `false`로 적는다.
